## 5. Environment deviations (docs/prereg.md §11)

The host has no Docker, no WSL2 and no administrator rights (`docs/SUBSTRATE-VALIDATION.md`). Therefore: isolation = native Windows processes with recorded command lines/PIDs/affinity; 'image digests' = SHA-256 of vendored archives + configuration hashes; resource limits = affinity mask, priority class, `-Xmx`, Hikari pool, broker/PG config; restart cadence = fresh topics/group/schema + fresh consumer JVMs per run, broker/PG processes restarted every 50 runs (D6). Broker failure is a process kill, not a machine loss (external-validity threat). All are reported in the paper's threats section and are present in every run record (`host`, `versions`, `process_limits`).
